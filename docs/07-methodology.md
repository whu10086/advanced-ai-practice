# 来源、筛选和许可说明

[返回首页](../README.md) · [资源目录](05-resource-catalog.md)

## 本轮范围

核验日期：2026-11-14（Asia/Shanghai）。面向完成基础课程后的应用进阶，重点检查官方组织或项目维护者的 GitHub 仓库，再从 README 定位官方文档、课程与论文。不把 Star 数当成质量或教学成效的证据。

资源分为工具、方法、课程、评测和研究基础设施。每项推荐应回答：解决什么问题、具体读哪里、学完做什么、怎样验收、需要哪些前置、会产生什么费用。

## 证据层级

1. GitHub 官方 API：仓库是否存在、标准名称、默认分支、归档状态、最近推送和自动识别的许可。
2. 当前 README：维护者声明、功能范围、安装入口、示例和弃用/迁移说明。
3. 实际许可证文件：纠正 `NOASSERTION` 或缺失识别，检查企业目录、数据集和单独授权的部分。
4. 官方教材与原论文：了解方法来源与进一步学习路径。

`updated_at` 可能受仓库元数据变化影响；`pushed_at` 更接近代码活动，但仍不等于发布质量。Continue 的例子表明，维护者的停维护声明可以早于 API 的归档标记。

## 推荐标签

- **优先实践**：与目标直接相关，有清晰开源许可和可用学习入口，适合作为第一轮作业。
- **专项进阶**：需要编程、评测或系统设计基础；适合在最小项目完成后使用。
- **方法阅读**：保留方法价值，维护较慢或依赖可能陈旧；部署前单独试跑。
- **补充参考**：有明显使用或复用条件，或内容成熟度需进一步检查。
- **历史参考**：已归档或明确停维护，保留用于架构研究。
- **待核实**：当前网络/API 未成功访问或没有确认许可，不能视为已完成推荐。

这些标签是本指南的编辑判断；最后推送和归档字段是抓取事实。具体映射见 [resources.json](../data/resources.json)。

## 许可证判读

MIT、Apache-2.0、BSD、AGPL 等许可证按各自条款使用。AGPL 带有相应的源码开放义务，不能与宽松许可证等同处理。课程的 CC BY-NC 4.0 含非商业限制，和允许商业复用的开源代码许可分开标注。

- n8n：Sustainable Use License，源码可用，存在内部用途、个人和非商业使用等限制。
- Dify：modified Apache，包含多租户及界面标识条件，不能简化为标准 Apache-2.0。
- Langfuse：开源核心 MIT，企业目录单独授权。
- Anthropic Skills：顶层 README 声明许多技能采用 Apache-2.0；应检查所用技能目录的 `LICENSE.txt`，逐项确认。
- MCP Servers：项目处于 MIT 向 Apache-2.0 的迁移，文档与规范另有区分，按文件及贡献适用许可处理。
- OpenAI Evals：代码 MIT，部分数据集有独立许可。
- Claude Code：顶层文本保留所有权利并引用商业服务条款，本指南不将其归类为可自由复用的开源代码。
- AI-Researcher：首轮未找到明确顶层许可，公开可见不足以证明允许再分发。

这里是选型记录，具体使用以相应版本的完整许可为准。

## 保存了什么

公开提交包括原创导读、模板、脚本、精简元数据与来源链接。完整 README/许可证下载到 `research/readmes/`、`research/licenses/`，仅作本地阅读缓存，已被 Git 忽略。未确认授权的上游材料不随本仓库重新发布。

[github-metadata.json](../research/github-metadata.json) 保留 UTC 核验时间与官方 API 来源。`readme_file` 和 `license_file` 是本地缓存位置，远程仓库读者应使用对应的 `*_url` 访问原文。API 失败会显式记录错误，不转换成“项目已停更”。

## 本轮验证的界限

已执行来源访问、README/许可审阅、目录记录检查与本地文档链接检查。没有逐项安装依赖、调用模型或测量工具效果，不能把文档审阅写成“全部跑通”。练习时长是编辑建议；模型与搜索费用取决于实际供应方、配置和用量。

刷新脚本会访问预设候选清单，属于可复现的来源审计。它不负责全网发现新项目，也不会自动更新人工解读、成熟度或许可分类。失败刷新会尽量保留上一次成功记录，并记录刷新错误与时间。
