# 三个最小实践作业

[返回首页](../README.md)

这些是可执行的作业设计，尚未预装模型或框架。优先使用自己已有的环境和公开样例，每个作业单独交付。

## 作业一：让 AI 完成一个可靠的代码变更

选一个已能运行的小项目，修复一个可复现缺陷或增加一个小功能。工具选 Codex / Aider，方法选 Spec Kit / OpenSpec 或手工模板。

提交：任务卡、最小修改、运行记录、一个完整提交。通过条件：能复现原问题；相关验收场景全部实际检查；说明未验证的环境；他人能按说明重跑。详见 [Coding 路线](../docs/01-ai-coding.md)。

## 作业二：把资料变成可核查周报

自备 5—10 份公开文本，用 Langflow 或 LangGraph 输出带来源的周报草稿。准备一份重复材料、一份缺正文材料和一份互相冲突材料。

提交：流程规格、配置/代码导出、样例输入输出、错误分支记录。通过条件：结构可校验；重复输入不会重复外发；每条关键结论能回到来源；不支持的结论进入待处理列表。详见 [工作流路线](../docs/02-ai-workflows.md)。

## 作业三：完成有证据的文献调研

限定一个小问题，精读两篇，再用 AI 辅助整理共 8—12 篇论文，填写证据矩阵；有余力再做直接问答与检索问答的小实验。

提交：检索记录、真实文献入口、原文定位、人工核验状态、综述草稿。通过条件：关键结论逐条支持；作者主张和自己推断分开；冲突材料完整保留；所有数字可回到论文原文或实际运行。详见 [学术路线](../docs/03-ai-research.md)。
